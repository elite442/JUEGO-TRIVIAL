# JUEGO-TRIVIAL

**DESCRIPCION DEL PROYECTO:**  
juego trivial es un juego de adivinar las preguntas desarrollado en C que implementas los conceptos de Algoritmos y Estructura de Datos 2. el objetivo del juego es adivinar correctamente 20 preguntas

**REQUSITO:**
tener la blibloteca RAYLIB v3.7

**COMO DESCARGAR LA BIBLOTECA:**
descargar el documento raylib-3.7.0 que esta en readme

**COMO COLOCAR LA LIBRERIA EN EL COMPILADOR:**
1_ acceder a la opcion de herramientas
2_ selecciona compiler options
3_ ve a Directories, luego selecciona libraries
4_ haz click en la carpeta y busca raylib-3.7.0_win64_mingw-w64
5_ entra en la carpeta y selecciona la carpeta lib y lo agregas
6_ luego te vas a C include, vuelves a seleccionar la misma carpeta y buscas la carpeta llamada include
